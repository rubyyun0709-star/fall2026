# Chaeeun Yun — Design Portfolio

Static site (HTML/CSS/JS, no build step). Layout inspired by Cargo-style split panes.

## Deploy on GitHub Pages
1. Create a new repository (e.g. `portfolio`) and upload everything in this folder.
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
3. Site goes live at `https://<username>.github.io/<repo>/` (name the repo `<username>.github.io` for a root URL).

## Edit
- Projects, text and image order: the `P` array in `script.js`; styling in `style.css`.
- Images: `assets/` (JPG, 2000px wide).
